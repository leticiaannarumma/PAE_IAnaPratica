## Agenda da Aula

1. **Transformar script em produto:** interface com Streamlit.
2. **Checklist de engenharia:** repositório pronto para avaliação.
3. **Preparação de demo:** narrativa curta e convincente.
4. **Hands-on:** montar MVP final do grupo.

---

## 1. Da automação ao produto

Até aqui, vocês criaram pipelines técnicos.
Agora, o objetivo é deixar isso utilizável por outra pessoa sem abrir o código.

No mínimo, a interface deve permitir:
* upload de arquivo (`st.file_uploader`) ou entrada de texto (`st.text_input`);
* execução do pipeline;
* exibição do resultado com tabela, métrica ou gráfico simples.

---

## 2. Estrutura mínima de entrega

Checklist obrigatório:
* `README.md` claro (problema, solução, como rodar).
* `requirements.txt` completo.
* `.env` no `.gitignore`.
* Código organizado em funções e com nomes legíveis.
* Uma rota principal funcional no app.

---

## 3. Roteiro de apresentação (5 a 7 min)

1. **Problema (1 min):** qual dor real está sendo resolvida.
2. **Solução (1 min):** como IA + dados foram usados.
3. **Demo ao vivo (3 min):** mostrar o fluxo funcionando.
4. **Desafio técnico (1 min):** obstáculo e como foi resolvido.

Regra prática: menos slides, mais produto rodando.

---

## 4. Hands-on: Fechamento do MVP

Objetivo da aula:
* colocar o app no ar localmente;
* revisar erros de execução;
* garantir previsibilidade para demo.

### Entregável da Aula
* repositório público atualizado;
* app Streamlit executando;
* demo pronta para apresentação.

---

## Fechamento do Curso

Vocês saem com um fluxo completo de mercado:
* dados brutos/desestruturados;
* processamento com Pandas;
* camada cognitiva com LLM (Structured Output ou RAG);
* interface funcional para utilizador final.
